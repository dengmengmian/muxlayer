## MuxLayer 2.0.8

CodeLeveler can use MuxLayer, and the built-in catalogs now list the models those vendors lead with.

CodeLeveler 可以走 MuxLayer。内置目录只保留各家当前主推的模型。

### CodeLeveler

- **One-click apply.** MuxLayer writes an OpenAI Chat provider into `~/.leveler/config.toml` (or `$LEVELER_HOME/config.toml`) and sets the default model to `muxlayer/muxlayer`. Other providers, models, and MCP servers stay. 客户端页一键接入。写入 OpenAI Chat 供应商，默认模型是 `muxlayer/muxlayer`。其它供应商、模型和 MCP 保留。

### Models

- **Old catalog rows are gone.** New OpenAI, Claude, Gemini, Grok, GLM, and MiniMax providers start from the current models. A provider you already saved keeps its model. Codex and Claude names those apps still send keep working. 新建供应商用当前模型。已经保存的供应商不改。Codex 和 Claude 仍会发来的旧名字继续能用。
