## MuxLayer 2.0.11

### Codex session compatibility / Codex 历史会话兼容

Resume chats bound to `deepseek` through MuxLayer. In **Clients → Codex → Apply Config**, enable **Resume DeepSeek sessions**, apply the configuration, and restart Codex. To resume chats bound to `OpenAI`, clear the option, apply again, and restart Codex.

绑定 `deepseek` 的 Codex 历史会话可以继续走 MuxLayer 中转。在 **客户端 → Codex → 应用配置** 中勾选 **兼容 DeepSeek 历史会话**，应用后重启 Codex。要续聊绑定 `OpenAI` 的会话，取消勾选后重新应用并重启。
