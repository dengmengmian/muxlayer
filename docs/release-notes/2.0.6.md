## MuxLayer 2.0.6

This release is mostly fixes. Backup providers now take over when one fails, switching a client back no longer wipes what you added, costs are closer to your real bill, and the gateway and the window both hold up better under load.

本版以修复为主：主 provider 挂了会切到备用，切回官方不再抹掉你后来加的东西，花费更接近真实账单，网关高并发和界面操作都不容易卡。

### Failover / 自动切换

- **Errors from a provider now switch to your backup.** A 429 or 5xx used to be passed straight back to you, and the provider was even marked healthy. Claude Code and Gemini CLI requests never switched at all. Now all four entry points switch the same way. 以前上游回 429、5xx 会直接把错误给你，还把这个 provider 记成健康。Claude Code 和 Gemini CLI 的请求根本不切。现在四个入口都会切到备用。
- **Request errors don't bench a provider.** A 400 like "prompt is too long" goes back to you as is and the provider stays in use. 请求本身的错误（比如「prompt 太长」）原样返回，不会把 provider 踢出去。
- **Once a reply has started, it is never retried.** You won't get half an answer followed by a second one. 已经开始回你内容的请求不会再重试，不会出现半截回答接着又来一遍。
- **Claude Code sees "overloaded" as it expects.** With a single provider, an overloaded Anthropic endpoint now returns 529 instead of a generic 502. 只有一个 provider 时，Anthropic 过载会回 529，不再是笼统的 502，Claude Code 能按过载处理。

### Clients / 客户端

- **Switching back to official keeps what you added.** MCP servers, hooks, and project trust added after Apply used to be erased by the old backup. Now only what MuxLayer wrote is removed. 切回官方以前会用旧备份整份覆盖，Apply 之后加的 MCP、hook、项目信任都会没。现在只删 MuxLayer 写进去的部分。
- **A config file MuxLayer can't read is left alone.** It used to be treated as empty and overwritten, which could wipe `~/.claude.json`. 读不了的配置文件以前会被当成空文件覆盖，`~/.claude.json` 可能被清空。现在直接报错，不动文件。
- **OpenCode keeps your other providers, and Gemini keeps the rest of `.env`.** OpenCode 里你自己加的 provider 不会被替换，Gemini 的 `.env` 里其它变量也会保留。
- **Stop process only lists the tool you applied.** Claude Desktop, the Grok app, and the Codex inside ChatGPT no longer show up by mistake. 「结束进程」不会再把 Claude Desktop、Grok 桌面版、ChatGPT 里的 Codex 列进来。
- **Restart Codex no longer quits ChatGPT.** It tells you when ChatGPT needs a manual restart, and the button only shows up when Codex Desktop is installed. 「重启 Codex」不再顺手关掉 ChatGPT，需要时会提醒你自己重启。没装 Codex 桌面端时不显示这个按钮。
- **Gemini CLI tool calls work through OpenAI-compatible providers.** Tool arguments were empty in streaming, and the next turn could fail with 400. Gemini CLI 接 OpenAI 兼容上游时，流式工具参数以前是空的，下一轮还可能 400。

### Protocols / 协议转换

- **Chat clients can turn on reasoning for Claude.** `reasoning_effort` used to cause a 400; newer Opus and Sonnet get the thinking mode they accept. Chat 客户端带 `reasoning_effort` 接 Claude 以前会 400，新的 Opus / Sonnet 也会用它们接受的思考方式。
- **Long Chinese replies no longer cut off.** A stream could break once its log passed 1 MB. 很长的中文回复以前流到一半会断。
- **Claude Code shows the right context size with OpenAI-style providers.** Cached tokens are no longer counted twice, so it won't compact too early. Claude Code 接 OpenAI 形态的上游时，缓存 token 不再算两遍，不会提前压缩上下文。
- **Requests without `stream` work.** Many SDKs leave it out; routed to Claude, that used to return 500. 很多 SDK 默认不带 `stream` 字段，这种请求路由到 Claude 时以前会 500。
- Images in tool results reach Claude, and images and `tool_choice` reach Gemini. 工具结果里的图片能传给 Claude，图片和 `tool_choice` 也能传给 Gemini。

### Costs / 花费

- **Claude Code traffic is counted.** Requests passed straight to an Anthropic endpoint used to record no tokens and no cost, so today's spend and the budget limit missed them. 直通 Anthropic 的请求以前不记 token 和花费，今日花费和预算闸都漏算。
- **Prompt cache is priced.** Cache reads and writes now count toward cost. 缓存读写计入花费。
- **"Today" means your local day.** It used to reset at 00:00 UTC. In Docker, set `TZ` or it stays UTC. 「今天」按你本地的日期算，以前按 UTC 零点。Docker 里要设 `TZ`，否则仍是 UTC。

### Speed / 更顺

- Logging and database work no longer block requests, and cleanup no longer rewrites the whole database every hour. 写日志、查库不再卡请求，定时清理也不会每小时重写整个数据库。
- The app stays responsive when clearing logs, loading big stats, or detecting clients. The Settings page no longer polls every second. 清空日志、看大范围统计、检测客户端时界面不再卡住，设置页也不再每秒刷新。
- A page error shows a message with a retry button instead of a blank window. 页面出错会显示提示和重试按钮，不再整窗白屏。
- **Easier to read.** Themes are now light and dark; the old Slate, Forest, and Violet themes switch over automatically. Tiny text is bigger, and colors pass contrast checks. 主题只保留浅色和深色，以前的 Slate、Forest、Violet 会自动切过去。小字调大了，颜色对比度也过了检查。

### Security / 安全

- Your database and token files are readable only by you. Exports hide API keys even without a known prefix. 数据库和 token 文件只有你自己能读。导出诊断包时，没有固定前缀的 key 也会被遮住。
- Redirects to another host are not followed, so provider keys can't leak through them. 不跟随跳到别的域名的重定向，provider 的 key 不会被带过去。
- The app window has a Content Security Policy. 应用窗口加了内容安全策略（CSP）。

### Heads-up / 注意

- **`/metrics` needs your token.** Add `Authorization: Bearer <token>` to your Prometheus scrape config; scraping by Docker service name still works. `/metrics` 现在要带 token，Prometheus 抓取配置里加上 `Authorization: Bearer <token>`，按 Docker 服务名抓取照常可用。
- **`docker-compose.yml` listens on `127.0.0.1` by default.** Change the `ports` line if other machines need to reach it. `docker-compose.yml` 默认只监听本机，要给别的机器用请改 `ports` 这一行。
- Rate limiting ignores `X-Forwarded-For` unless you set `MUXLAYER_TRUST_PROXY=1` behind a reverse proxy. 限流默认不信 `X-Forwarded-For`，放在反向代理后面时请设 `MUXLAYER_TRUST_PROXY=1`。
- After the first start, cost for past requests is filled in in the background, so older numbers can change shortly after. 升级后第一次启动会在后台补算历史请求的花费，旧的统计数字会随之更新。
