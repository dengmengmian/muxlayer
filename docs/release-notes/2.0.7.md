## MuxLayer 2.0.7

DeepSeek now offers only two models, `deepseek-flash` and `deepseek-v4-pro`. This release follows that change.

DeepSeek 现在只有 `deepseek-flash` 和 `deepseek-v4-pro` 两个模型，本版跟着调整。

### DeepSeek

- **`deepseek-flash` is the default model and reads images.** Images you send go straight to it instead of being removed. `deepseek-flash` 是默认模型，能直接看图，发过去的图片不再被去掉。
- **`deepseek-v4-pro` is still text-only.** Images sent to it are removed, with a note telling the model an image was there. `deepseek-v4-pro` 仍然只收文字，发给它的图片会去掉，并告诉模型这里原本有图。
- **Existing setups update themselves.** If your DeepSeek provider, model mappings, or routes still use `deepseek-v4-flash` or `deepseek-v4-flash-vision-exp`, they switch to `deepseek-flash` the first time you start this version. 如果你的 DeepSeek provider、模型映射或路由还在用 `deepseek-v4-flash` 或 `deepseek-v4-flash-vision-exp`，升级后第一次启动会自动换成 `deepseek-flash`。
