## MuxLayer 2.0.9

> **Agent Gateway is still a test feature / Agent Gateway 仍是测试性功能。** Interfaces and behavior may change, and it is not recommended for production-critical workflows. 接口和行为可能调整，不建议用于关键生产流程。

MuxLayer can now connect Codex and Claude Code to MCP-capable apps. Installing MuxLayer is enough — the desktop app includes the Agent Gateway CLI.

现在可以把 Codex 和 Claude Code 接到支持 MCP 的应用。装 MuxLayer 就够了，桌面端已内置 Agent Gateway CLI。

### Agent Gateway

- **Choose, connect, use.** Pick a detected Agent, connect Pi or CodeLeveler over MCP, then call `agent_list` / `agent_run` from the client. 选择 Agent、通过 MCP 接入 Pi 或 CodeLeveler，然后在客户端调用 `agent_list` / `agent_run`。
- **Real sessions.** Continue a task, cancel a running task, and read the final answer after a service restart. 支持连续任务、取消，以及服务重启后读取最终回答。
- **Read-only.** Agent runs use read-only permissions and do not modify your project. Agent 任务使用只读权限，不修改项目文件。
- **One install.** The bundled CLI is installed at `~/.muxlayer/bin/agentgate-serve`; there is no separate CLI download. 内置 CLI 安装到固定路径，不需要单独下载。
- **Independent service.** The model gateway and Agent Service start according to settings and fail independently. Closing the desktop window does not stop a running Agent task. 模型网关和 Agent Service 按设置启动、互不影响；关闭桌面窗口不会停掉正在运行的 Agent 任务。

### Notes

- Codex or Claude Code must already be installed and signed in. 需要先安装并登录 Codex 或 Claude Code。
- CodeLeveler versions without the MCP `isError` fix show an upgrade warning. 不含 MCP `isError` 修复的 CodeLeveler 版本会显示升级提醒。
