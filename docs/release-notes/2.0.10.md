## MuxLayer 2.0.10

> **Agent Gateway is still a test feature / Agent Gateway 仍是测试性功能。** Interfaces and behavior may change, and it is not recommended for production-critical workflows. 接口和行为可能调整，不建议用于关键生产流程。

This patch fixes Agent Gateway startup on Linux and updates several dependencies with security fixes.

本次补丁修复 Linux 上 Agent Gateway 的启动问题，并更新了多个带安全修复的依赖。

### Fixes

- **Linux Agent Gateway startup.** On Linux, `/bin/sh` is dash, which sends a background job's stdin to `/dev/null`. Codex and Claude Code children exited immediately after launch. The supervisor now preserves stdin through a dedicated fd. Linux 上 dash 会把后台任务的 stdin 接到 `/dev/null`，导致 Codex / Claude Code 子进程启动后立即退出；Supervisor 现在通过独立 fd 传递 stdin。
- **Dependency security updates.** Upgraded `zip` to 9.0.5, `rustls` to 0.23.46, and `tauri-plugin-updater` to 2.14.0. 升级 `zip`、`rustls` 和 `tauri-plugin-updater`，修复已知安全漏洞。
